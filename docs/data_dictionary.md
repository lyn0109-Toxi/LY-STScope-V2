# REIT Data Dictionary

| Field | Meaning | Educational Use |
| --- | --- | --- |
| Symbol | Ticker symbol | Search and comparison |
| Company | REIT name | Identification |
| REIT Sector | Property specialization | Sector focus and peer grouping |
| Price | Current market price | Market reference |
| Dividend Yield | Dividend / price | Income analysis |
| Price to FFO | Price / funds from operations | REIT valuation multiple |
| AFFO Payout | Dividends / adjusted FFO | Dividend sustainability |
| NAV Discount | Price versus estimated NAV | Asset-based valuation |
| Debt to EBITDA | Leverage indicator | Financial risk |
| Occupancy | Property utilization | Operating quality |
| Beta | Market sensitivity | CAPM and portfolio risk |
| Rate Sensitivity | Estimated sensitivity to interest rates | Macro risk |
